Welcome to **ai-playgrounds**! This is a collection of fun, hands-on labs that help you understand how artificial intelligence works. You don't need to be a programmer or a math wizard to use it. Everything runs in your web browser, and you learn by clicking, dragging, and experimenting.

Think of it like a science museum for AI. Instead of reading long explanations, you get to play with working models of search algorithms, neural networks, and even teach a computer to recognize handwritten numbers. ## 🛠️ Troubleshooting & FAQ

### 🚫 The app doesn't open after double-clicking

Try right-clicking the downloaded file and selecting **Run as administrator**. Also, double-check that you downloaded the correct file for Windows (it might have a `.exe` suffix if that's how it was packaged). If it still doesn't work, make sure your browser is up to date.

### 🌐 I see a blank page when the app starts

Wait a few seconds. The first launch can take a little longer because the app is loading all the lab files. If it stays blank, refresh the browser tab (press F5).

###🔄 How do I update ai-playgrounds?

Check the same download page regularly. When a new version is released, download it and run it. Your saved progress (if any) from previous versions is stored in your browser and will still be available.

### 📁 Where are my saved experiments?

This app doesn't save experiments to your hard drive. Everything runs in the browser's memory. If you want to save a screenshot, just press the Print Screen key on your keyboard.

### ❓ I have another question

The source code is public, and you can look at the project's discussions section on the same download page. The community is friendly and often responds quickly.
